Hugging Face Access Token

Paste your token (starts with hf_). It will be stored in your browser’s localStorage for convenience.

  • Get it from Hugging Face: Settings → Access Tokens
  • Create a token with at least “read” access.
  • Security note: any token used in the browser can be extracted by anyone who can run the page. Use a backend proxy for real deployments.
